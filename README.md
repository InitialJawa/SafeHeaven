## 🚀 Fitur & Kapabilitas Unggulan

### 📊 1. Mesin Pembobotan Saham Kuantitatif (Multi-Factor Scoring)
* **Algoritma Scoring 6 Dimensi**: Setiap saham di semesta IHSG (LQ45, Kompas100, IDX30, dsb.) dievaluasi secara matematis dengan pembobotan kustom:
  * 💎 **Quality**: ROE, ROIC, Profit Margin, Debt-to-Equity.
  * 💰 **Value**: PER, PBV, EV/EBITDA vs Median Industri.
  * 🚀 **Growth**: Revenue Growth, EPS Growth YoY/QoQ.
  * ⚡ **Momentum**: RSI, Relative Strength vs IHSG, Price Distance to MA.
  * 📊 **Volume & Liquidity**: Trading Value Average, Foreign Flow Accumulation.
  * 🎁 **Dividend Yield**: Sustainability, Payout Ratio, Dividend Track Record.
* **Filter & Screener Fleksibel**: Pengguna dapat mengubah bobot tiap faktor secara live untuk mencocokkan profil risiko pribadi.

---

### 🛡️ 2. Alokasi Aset Dinamis & Auto-Switch Emas / Cash
* **Deteksi Regime Pasar Otomatis**: System memantau kondisi IHSG secara *real-time* (*Bullish Rally, Neutral Sideways, High Volatility, Crisis Mode*).
* **Proteksi Modal Otomatis (Asset Shield)**:
  * **Regime Bullish**: Alokasi optimal ke saham-saham skor tertinggi (misal 80% Saham, 10% Emas, 10% Cash).
  * **Regime Bearish / Panic**: Sistem secara otomatis mengusulkan rebalance memindahkan porsi terbesar modal ke **Emas (Gold)** dan **Cash / USD** untuk memangkas *Maximum Drawdown*.
* **Circuit Breaker & Stop-Loss Level**: Pengaturan *Maximum Single Stock Allocation* dan *Auto Stop-Loss* otomatis untuk mencegah kepemilikan terkonsentrasi.

---

### 🧪 3. Quantitative Backtest Lab & Strategi
* **Pilihan Strategi Kuantitatif Ternama**:
  * 👑 **Warren Buffett Quality-Value**: Fokus saham ROE tinggi, utang rendah, valuation diskon.
  * 🚀 **Momentum Alpha Breakout**: Berburu saham beradrenalin tinggi dengan dorongan volume & tren kuat.
  * 🛡️ **Dividend aristocrats**: Saham dividen tinggi dan konsisten untuk *passive income*.
  * ⚖️ **Risk Parity & Defensive**: Kombinasi seimbang antara saham defensif dan aset pelindung nilai (Emas).
* **Fitur Backtesting Lanjutan**:
  * **Walk-Forward Historical Testing**: Uji strategi melintasi berbagai periode histori IHSG.
  * **Metrik Risiko Lengkap**: CAGR, Sharpe Ratio, Sortino Ratio, Max Drawdown, Win Rate, & Profit Factor.
  * **Simulasi Rebalancing Periode**: Pengujian rebalance bulanan, kuartalan, atau otomatis berbasis ambang batas (*threshold trigger*).

---

### 🤖 4. Gemini AI Stock & Portfolio Advisor
* **Reasoning AI Kuantitatif 24/7**: Google Gemini AI menganalisis struktur portofolio Anda, memberikan penjelasan rasional mengapa saham tertentu disarankan di-*BUY*, *HOLD*, atau *TRIM*.
* **News & Sentiment Correlation**: Menggabungkan sentimen berita makroekonomi dengan indikator fundamental pasar.
* **Server-Side Security**: Seluruh panggilan Gemini dikelola aman melalui `/api/ai/*` di backend Express.

---

### 💳 5. Fitur Monetisasi & Akses Premium (Saweria Gateway)
* **Paket Akses Pro & Premium VIP**: Menyediakan fitur gratis untuk pemula serta Paket **Pro** & **Premium VIP** untuk trader pro yang membutuhkan kuantum penuh & rebalance otomatis.
* **Direct Integration**: Pembayaran langganan terintegrasi dengan gateway Saweria & aktivasi instan dari **Admin Console**.

---

## 🏢 Operasi & Panel Admin (`/admin`)

Panel Mission Control terintegrasi mencakup 9 modul utama:
1. **Overview & System Metrics**: Monitor kesehatan server, kuota AI, dan metrik sistem.
2. **Saweria & Payment Console**: Pengaturan link pembayaran, nama merchant, dan pengaktifan peran member VIP.
3. **Stress & Crisis Simulator**: Simulasi efek krisis pasar (*Crash 2008, COVID Panic, Fed Rate Hike*) terhadap portofolio.
4. **Risk Control**: Pengaturan limit alokasi saham tunggal dan pengereman krisis.
5. **Rebalance Lab**: Eksekusi rebalancing massal portofolio pengguna.
6. **Broadcast Console**: Pengiriman pengumuman sinyal pasar ke seluruh member.
7. **User Management**: Pengelolaan peran (*Admin, Advisor, Free User*).
8. **Database Console**: Manajemen database SQLite (`safehaven.db`) dan sinkronisasi Firestore.
9. **Audit Terminal**: Log jejak audit aktivitas sistem.

## ⚡ Panduan Memulai Development

### 1. Prasyarat
- **Node.js**: v18+ 
- **npm**: v9+

### 2. Install Dependensi & Environtment
```bash
# Clone repository
git clone https://github.com/YourRepo/SafeHaven.git
cd SafeHaven

# Install paket
npm install

# Salin env file
cp .env.example .env
```

### 3. Jalankan Server Dev
```bash
npm run dev
```
Buka **`http://localhost:3000`** di browser Anda.
